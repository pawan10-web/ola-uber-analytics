    About this project

    This project analyses Ola ride bookings (Bengaluru, July 2024) to understand demand, cancellations, payments and customer behaviour. The original version used MySQL Workbench and Power BI; this version turns the same analysis into a web application that runs locally in the browser.

    Data pipeline

    1. IngestBookings.csv (raw, 103k lines)
    2. Cleandrop blank rows, convert "null" → NULL, fix types & time format
    3. StoreSQLite database with indexes
    4. AnalyseSQL aggregations & window functions
    5. ServeFlask REST API returning JSON
    6. Visualiseinteractive charts in the browser

    Tech stack

    Python · Flask · SQLite · HTML/CSS/JavaScript (hand-written SVG charts, no external libraries, works offline).

    Data quality notes

    • The raw CSV contains about 82,617 completely empty rows and a trailing empty column; both are removed during ingestion.
    • Ratings, payment method and TAT fields exist only for successful bookings; reasons exist only for the matching cancellation type, so those columns are legitimately NULL elsewhere.
    • Booking_Value is also present on cancelled rides, so revenue is always computed on Booking_Status = 'Success'.
